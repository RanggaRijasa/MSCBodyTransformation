# Prompt GPT ImageGen

Mode: built-in GPT ImageGen  
Use case: `ui-mockup`

## Mode Peserta

```text
Design a high-fidelity native iOS Admin program preview in participant mode.
Replace the device-size segmented control with Peserta | Coach. Peserta is
selected. Add a compact explanation banner outside the shared renderer.
Render a compact program header, progress, and day accordions identical to
the Participant program screen. Open Hari ini with Timbang awal marked
Selesai and Mengenal targetmu marked Menunggu pemeriksaan. Show Besok locked
with Aktivitas belum tersedia. Keep the Admin floating tab bar with Program
selected. Use Bahasa Indonesia, San Francisco, neutral surfaces, red brand
emphasis, semantic green/yellow status badges, icon plus text, and practical
44-point touch targets. No device-size control, duplicate CTA, excessive
whitespace, English copy, logo, or watermark.
```

## Mode Coach

```text
Design the Coach counterpart of the same native iOS Admin program preview.
Coach is selected in Peserta | Coach. Add the explanation banner and one
compact Peserta yang dipantau row for Ayu Lestari. Preserve the exact program
header, dates, progress, day order, step names, and status language used in
participant mode. Coach sees Timbang awal as Tercatat without a weight value,
and Mengenal targetmu as Menunggu pemeriksaan. The future day remains locked.
Keep the Admin floating tab bar with Program selected. Use Bahasa Indonesia,
semantic status styling, icon plus text, and no photo/weight disclosure,
duplicate CTA, English copy, logo, or watermark.
```

Exact expanded prompts used for generation are represented by these product
constraints and the accompanying plan. The four supplied screenshots were
used as style and composition references, not as edit targets.
