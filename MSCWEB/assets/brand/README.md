# MSC app icon source

`AppIcon-Default.png` is a repository-local copy of the approved native MSC app
icon from
`MSCBodyTransformation/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon-Default.png`.
It was copied into the web boundary on 2026-08-12 so icon generation remains
self-contained if `MSCWEB/` is split into its own repository.
