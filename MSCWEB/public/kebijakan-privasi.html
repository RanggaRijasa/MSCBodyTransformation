MSC Body Transformation Buka aplikasi

Kebijakan privasi

Berlaku sejak 21 Agustus 2026. Kebijakan ini menjelaskan bagaimana MSC Body Transformation, yang berkedudukan di Indonesia, memproses data pada situs dan PWA.

Data yang diproses

Kami dapat memproses nama, email, nomor HP, ID akun, foto profil, peran, pengajuan Coach, keikutsertaan program, jawaban, berat badan, foto bukti aktivitas, skor, bukti pembayaran manual, keputusan pemeriksaan, serta data teknis terbatas untuk keamanan dan dukungan.

Tujuan penggunaan

Data digunakan untuk autentikasi, profil, program, hubungan Peserta dan Coach, pemeriksaan kiriman, skor, leaderboard tanpa berat badan, akses berbayar, pengajuan Coach, keamanan, pencegahan penyalahgunaan, dan dukungan.

Google Auth dan Supabase

Login web memakai Google melalui Supabase Auth. Supabase menyediakan autentikasi, database, fungsi server, dan penyimpanan media. Kami tidak meminta atau menyimpan password Google Anda.

Pembayaran manual dan retensi

Bukti transfer atau QRIS disimpan pada penyimpanan privat dan diperiksa Admin. Kami tidak meminta PIN, OTP, password perbankan, atau data kartu. File gambar bukti dihapus 30 hari setelah diunggah. Bila masih diperiksa pada hari ke-30, file dipertahankan sampai keputusan dicatat lalu dihapus. Metadata transaksi, ledger, keputusan, dan audit dapat dipertahankan lebih lama untuk keamanan, sengketa, dan kewajiban hukum.

Foto, berat badan, dan wellness

Foto bukti dan berat badan merupakan data sensitif. Akses dibatasi sesuai peran dan kebutuhan program. Metadata gambar yang tidak diperlukan, termasuk lokasi, dihapus sebelum unggah bila didukung. Layanan ini berfokus pada wellness dan tidak memberikan diagnosis atau saran medis.

Insight makanan melalui OpenRouter

Jika langkah program mengaktifkannya, foto makanan dapat diproses server melalui OpenRouter dengan Gemma 4 26B A4B sebagai model utama dan Gemma 3 12B sebagai fallback. Hanya byte gambar yang dinormalisasi dan rubrik minimum yang dikirim; nama, email, berat badan, object path, signed URL, dan identitas akun tidak dikirim. Provider hosting aktual dapat berubah sesuai ketersediaan dan batas harga. Pemrosesan, retensi, logging, dan penggunaan data mengikuti pengaturan privasi akun production serta kebijakan provider; Zero Data Retention tidak dipaksakan oleh aplikasi. Hasil AI hanya perkiraan, dapat gagal, bukan diagnosis, dan tidak memengaruhi approval, poin, atau leaderboard.

Pembagian dan penjualan data

Data dibagikan hanya kepada penyedia yang diperlukan, termasuk Google, Supabase, OpenRouter, dan provider model yang memenuhi kebijakan request. Kami tidak menjual data pribadi untuk periklanan dan tidak melacak pengguna lintas situs milik pihak lain.

Penghapusan dan keamanan

Data disimpan selama akun, program, transaksi, audit, keamanan, atau kewajiban hukum memerlukannya. Penghapusan akun mencabut sesi dan menghapus data pribadi/media sesuai kontrak produk. Media privat tidak dimasukkan ke cache publik atau dibagikan melalui URL permanen.
